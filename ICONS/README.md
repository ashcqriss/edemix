# ICONS

Reserved for the dedicated Edemint icon set (app icons, folder icons, MIME,
status and action glyphs, with symbolic variants and HiDPI sizes).

The final artwork follows in later commits, as announced in the bp_des_5
design brief. Until then the shell and apps use themed freedesktop icon names
so every reference here can be swapped in without code changes.

Requirements recorded from the brief:

- Rounded-rectangle shape language; production icons smaller than the
  blueprint placeholders.
- Palette compliance per `docs/PALETTE.md` (ultramarine/azure lead, navy
  anchor, plant/eco/turquoise support; warm colors only for owned semantics).
- Dynamic/spontaneous icon states are expected later (e.g. active/inactive
  dock states); keep sources layered so states can be derived.
